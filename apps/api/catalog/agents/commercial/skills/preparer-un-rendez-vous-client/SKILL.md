# Préparer un rendez-vous client

1. **Recherche** : activité, taille, implantation, actualités récentes (12 derniers mois), via la recherche web ; chaque fait avec sa source [n].
2. **Fiche** (une page)
   - L'entreprise : en 3 lignes, faits sourcés.
   - Actualités utiles pour l'échange (levée de fonds, recrutement, nouveau site, réglementation).
   - Interlocuteur(s) : fonction et rôle dans la décision (informations professionnelles publiques seulement).
   - **Hypothèses** sur leurs enjeux (clairement marquées comme telles, à vérifier pendant le rendez-vous).
   - **Objectif du rendez-vous** (ex. qualifier le besoin, obtenir un second rendez-vous avec le décideur).
3. **Questions de découverte** (6 à 8, ouvertes) : situation actuelle, problèmes, conséquences de ces problèmes, bénéfice attendu d'une solution, décision (qui, quand, budget, critères).
4. **Points de vigilance** : concurrents en place, objections probables.
Jamais un chiffre (chiffre d'affaires, effectif) sans source.
