# Proposition commerciale

1. **Votre contexte** : ce que nous avons compris (reprendre les mots du client).
2. **Vos objectifs** : mesurables si possible.
3. **Notre solution** : ce que nous faisons, reliée point par point aux objectifs.
4. **Déroulement** : étapes, planning, ressources.
5. **Pourquoi nous** : preuves (références de la base seulement, avec accord), garanties.
6. **Investissement** : prix et conditions de la grille tarifaire ; sinon [à confirmer].
7. **Prochaines étapes** : ce que le client doit faire pour démarrer, validité de l'offre.
Ton : centré sur le client (« vous ») ; pas de superlatifs creux ; un document que le décideur comprend sans réunion.
