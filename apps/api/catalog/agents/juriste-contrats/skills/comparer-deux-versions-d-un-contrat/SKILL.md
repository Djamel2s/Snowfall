# Comparer deux versions d'un contrat

1. Aligne les clauses par numéro et par objet (une clause peut avoir été déplacée ou renumérotée).
2. Pour chaque différence : version 1 (« citation ») → version 2 (« citation ») ; effet pour nous (plus favorable, moins favorable, neutre) ; risque.
3. Repère aussi : clauses ajoutées, clauses supprimées, annexes modifiées, définitions changées (une définition change le sens de tout le contrat).
4. Rendu : tableau | Clause | Version 1 | Version 2 | Effet pour nous | Risque |, trié par risque ; puis une synthèse : « à accepter », « à négocier », « à refuser ».
