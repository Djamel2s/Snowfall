# Revue de contrat (B2B, droit français)

## Avant la grille
Type de contrat ; parties ; notre position (client / prestataire) ; objet ; montant et durée s'ils sont indiqués. Si notre position est inconnue : demande-la.

## Grille (pour chaque point : présent ? que dit-il ? risque pour NOUS ?)
1. **Objet et périmètre** : prestations décrites précisément ? Livrables, niveaux de service (SLA) ?
2. **Durée, renouvellement** : durée ferme ; tacite reconduction (durée, préavis pour s'y opposer) ; un engagement long avec reconduction tacite et préavis court ou difficile est un risque élevé pour le client.
3. **Prix et révision** : prix ferme ou révisable ; indice et formule ; plafond de hausse.
4. **Paiement** : délais (pour les entreprises, le Code de commerce plafonne les délais de paiement : à vérifier selon le cas), pénalités de retard.
5. **Responsabilité** : plafond (montant ou multiple du prix annuel) ; exclusions (dommages indirects) ; une responsabilité ILLIMITÉE à notre charge est un risque élevé ; une exclusion totale de la responsabilité de l'autre partie aussi. Rappel : on ne peut pas exclure sa responsabilité pour faute lourde ou dolosive.
6. **Garanties et assurances** : garanties de conformité ; attestation d'assurance demandée ?
7. **Propriété intellectuelle** : qui détient les livrables ? Cession (droits, durée, territoire, supports) ou licence ? Pour être valable, une cession de droits d'auteur doit énumérer les droits cédés.
8. **Confidentialité** : réciproque ? durée (y compris après la fin) ? exceptions ?
9. **Données personnelles** : un traitement pour notre compte ? → clauses de l'article 28 du RGPD (compétence dédiée). Transferts hors UE ?
10. **Sous-traitance** : autorisée ? avec notre accord ? responsabilité maintenue ?
11. **Résiliation** : pour manquement (mise en demeure, délai) ; pour convenance ; indemnités ; conséquences (réversibilité, restitution des données).
12. **Réversibilité** (services, informatique) : assistance à la sortie, formats, coûts.
13. **Force majeure** : définition, durée, résiliation au-delà.
14. **Non-sollicitation** du personnel : durée, indemnité (proportionnée ?).
15. **Loi applicable et juridiction** : loi française ? tribunal compétent ; médiation préalable ?
16. **Clauses déséquilibrées** : entre professionnels, un déséquilibre significatif peut être sanctionné (Code de commerce) : signale-les.

## Niveaux de risque
- **Élevé** : expose à une perte importante ou non plafonnée, à une illégalité (RGPD), ou nous enferme (engagement long sans sortie).
- **Moyen** : défavorable mais négociable ; flou qui créera des litiges.
- **Faible** : amélioration de rédaction.
