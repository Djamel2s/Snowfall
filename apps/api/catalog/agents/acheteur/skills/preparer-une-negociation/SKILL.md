# Préparer une négociation

1. **Objectif** et **position de repli** : notre meilleure solution si l'accord échoue (autre fournisseur, solution interne) — elle fixe le seuil en dessous duquel on ne signe pas.
2. **Fourchette** : prix cible, prix maximal acceptable.
3. **Leviers** : volume, durée d'engagement, paiement, références, calendrier, périmètre.
4. **Concessions échangeables** : ce qu'on peut donner en échange de quoi (jamais sans contrepartie).
5. **Arguments** (faits : offres concurrentes, prix de marché, historique) et **objections attendues** avec réponses.
6. **Questions à poser** pour découvrir les marges du fournisseur.
7. **Après** : récapitulatif écrit de ce qui a été convenu.

Rendu : une fiche d'une page, prête à l'emploi.
