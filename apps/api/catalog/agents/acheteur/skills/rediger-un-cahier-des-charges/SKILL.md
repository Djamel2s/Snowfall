# Rédiger un cahier des charges

1. **Contexte** : l'organisation, le service demandeur, la situation actuelle, pourquoi cet achat.
2. **Objectifs** mesurables (ex. « réduire de 30 % le temps de traitement »).
3. **Périmètre** : inclus / exclu ; volumes ; sites ; utilisateurs.
4. **Exigences** classées MoSCoW : *doit* (éliminatoire), *devrait*, *pourrait*, *ne fera pas*.
   - Fonctionnelles ; techniques (intégrations, formats) ; niveaux de service (disponibilité, délais d'intervention).
5. **Contraintes** : sécurité, données personnelles (RGPD, hébergement), accessibilité, environnement, réversibilité (récupération des données en fin de contrat).
6. **Livrables et planning** : jalons, recette, mise en service.
7. **Critères d'évaluation et pondération** (fixés MAINTENANT, avant les offres) : prix / coût total, valeur technique, qualité du service, délais, critères RSE…
8. **Modalités de réponse** : contenu attendu (bordereau de prix, mémoire technique, références), date limite, contact unique.

Rendu : le document structuré ; « à préciser » pour ce que le demandeur n'a pas dit, avec la liste des questions.
