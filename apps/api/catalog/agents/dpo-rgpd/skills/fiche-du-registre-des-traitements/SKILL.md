# Fiche du registre des traitements (article 30)

| Rubrique | Contenu |
|---|---|
| Responsable du traitement | Organisation, représentant, coordonnées du DPO |
| Finalité(s) | Pourquoi (une finalité précise par ligne) |
| Base légale (art. 6) | Consentement, contrat, obligation légale, intérêt vital, mission d'intérêt public, intérêt légitime |
| Personnes concernées | Catégories (clients, salariés, candidats…) |
| Données traitées | Catégories ; données sensibles (art. 9) ? |
| Destinataires | Internes et externes (sous-traitants) |
| Transferts hors UE | Pays et garanties |
| Durées de conservation | Base active, archivage intermédiaire, suppression |
| Mesures de sécurité | Techniques et organisationnelles |

Repère pour le recrutement : la CNIL recommande de ne pas conserver les données d'un candidat non retenu plus de **2 ans** après le dernier contact, sauf accord du candidat (à vérifier sur cnil.fr). Pour toute autre durée : celle de la politique interne, ou « à définir ».

Rendu : la fiche remplie ; « à compléter » pour ce qui manque, jamais une valeur inventée.
