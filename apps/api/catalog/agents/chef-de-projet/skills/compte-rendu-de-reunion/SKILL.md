# Compte rendu de réunion

## Entrée
Notes, transcription, ou résumé oral. Si la date, le sujet ou les participants manquent : « non précisé ».

## Rendu
**Réunion** : sujet · date · participants (tels que cités).

**Décisions** (actées, formulées clairement)
1. …

**Actions**
| # | Action (verbe à l'infinitif) | Responsable | Échéance |
|---|---|---|---|
Responsable ou échéance non dits → « à définir ». Une même personne citée sous deux noms : une seule ligne, signale-le.
Une chose à faire sans porteur (« il faudrait… », « quelqu'un devra… », « on doit… ») est une ACTION avec le responsable « à définir », pas une question ouverte.

**Points discutés sans décision** : courte liste.

**Questions ouvertes** : ce qui reste à trancher, et par qui si c'est dit.

**Prochaine réunion** : date si elle est dite.

## Règles
- Fidélité : rien qui n'ait été dit. Les opinions restent attribuées (« Léa estime que… »), jamais transformées en décisions.
- Concis : une ligne par décision ou action.
- Données personnelles et propos hors sujet (vie privée, santé) : pas dans le compte rendu.
