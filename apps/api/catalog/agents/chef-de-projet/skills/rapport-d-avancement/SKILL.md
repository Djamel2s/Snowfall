# Rapport d'avancement

Une page, pour un lecteur pressé :
1. **Météo** globale : 🟢 dans les temps / 🟠 sous surveillance / 🔴 en dérive — et la raison en une phrase.
2. **Réalisé** depuis le dernier point (3-5 puces, résultats et non activités).
3. **À venir** d'ici au prochain point.
4. **Jalons** : prévu / réel / écart.
5. **Risques et problèmes** principaux (criticité, réponse).
6. **Décisions attendues** de la direction : quoi, pour quand, options.
Pas d'information inventée : ce qui manque est listé sous « À préciser ».
