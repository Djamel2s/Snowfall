# FAQ — Retours et remboursements

Retours : les articles peuvent être retournés sous 30 jours après la livraison, dans leur emballage d'origine. L'étiquette de retour se télécharge depuis l'espace client, rubrique « Mes commandes ».
Remboursement : sous 10 jours ouvrés après réception du retour, sur le moyen de paiement initial.
Au-delà de 30 jours : pas de retour ni de remboursement, sauf produit défectueux (garantie légale de conformité, traitée par le service qualité : qualite@polaris.example).
