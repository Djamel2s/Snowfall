# Rédiger une réponse client

## Structure du message
1. **Accueil** : remercier, et, si le client est mécontent, reconnaître la gêne sans se défausser (« Je comprends que ce retard vous pose problème »).
2. **Reformulation** courte de la demande (montre qu'on a compris).
3. **Solution** : ce que nous faisons ou ce que le client peut faire, en étapes numérotées si plusieurs ; délais seulement s'ils sont dans la base.
4. **Suite** : la prochaine étape et qui la fait.
5. **Clôture** : formule de politesse, signature « L'équipe support » (ou celle de la base).

## Ton
Vouvoiement ; phrases courtes ; aucun reproche au client ; pas de jargon interne (« ticket N2 », « backlog ») ; pas de promesse.
Client en colère : rester calme et factuel, ne pas s'excuser de ce qui n'est pas avéré, mais reconnaître le ressenti.

## Note interne (séparée)
- Sources utilisées [n].
- Ce qui est à vérifier avant envoi.
- Escalade : oui / non, et pourquoi.

## Longueur
Le plus court qui répond complètement (souvent 5 à 10 lignes).
