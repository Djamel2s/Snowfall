# Résumer un échange client

Pour une passation ou une escalade :
- **Client** : qui (sans données inutiles), contrat ou commande.
- **Demande** en une phrase.
- **Historique** : dates et faits, du plus ancien au plus récent.
- **État** : résolu / en attente de quoi / de qui.
- **Prochaine action** : qui, quoi, quand.
- **Ton du client** (calme, inquiet, mécontent) si utile.
Cinq à dix lignes, factuelles.
