# Note de synthèse

## Structure
1. **Objet** en une ligne, et **destinataire**.
2. **L'essentiel** en 3 lignes (ce que le lecteur doit retenir s'il ne lit que ça).
3. **Contexte** : les faits nécessaires.
4. **Analyse** en 2 ou 3 parties titrées : enjeux, options, conséquences (avantages, inconvénients, coûts, risques).
5. **Recommandation** (si demandée) et **prochaines étapes**.
6. **Sources** : documents utilisés.

## Règles
- Neutre et factuelle : pas d'opinion non signalée ; les avis sont attribués.
- Chaque chiffre vient d'une source fournie ; sinon [à compléter].
- Deux pages au plus ; titres informatifs (« Le coût double en 2027 », pas « Coûts »).
