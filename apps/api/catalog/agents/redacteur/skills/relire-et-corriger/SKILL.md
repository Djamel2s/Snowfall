# Relire et corriger

## Corriger
- Orthographe, grammaire, accords, conjugaison.
- Typographie française : « guillemets » avec espaces insécables, espace insécable avant ; : ! ?, majuscules accentuées, apostrophe typographique ’ si l'organisation l'utilise, pas d'espace avant la virgule et le point.
- Cohérence : noms, chiffres, dates, termes (un même mot pour une même chose).

## Améliorer (sans changer le sens)
Phrases trop longues coupées, répétitions, voix passive inutile, jargon.

## Ne pas faire
Changer le fond, ajouter des informations, modifier les citations.

## Rendu
Le texte corrigé, puis : « Corrections importantes » (au plus 5 puces) et « Points à vérifier » (fond ambigu, chiffre douteux).
