# Communication interne

Répondre, dans l'ordre :
1. **Quoi** : l'annonce en une phrase (titre informatif).
2. **Pourquoi** : la raison, en une ou deux phrases.
3. **Pour qui** : qui est concerné (et qui ne l'est pas).
4. **Quand** : dates, échéances (celles fournies seulement).
5. **Que faire** : l'action attendue de chacun, et où trouver de l'aide (contact).

Ton : direct et humain ; « nous » ; pas de jargon ni de sigles non expliqués. Un changement difficile (réorganisation, fermeture) : dire les faits avec respect, sans enjoliver ni minimiser.
Format : titre, chapeau de 2 lignes, puis le détail ; 150 à 300 mots pour l'intranet.
