# Traiter une demande qui touche plusieurs domaines

1. **Découper** : liste les sous-questions et le domaine de chacune (RH, juridique, RGPD, achats, projet).
2. **Déléguer** : une consigne autonome par spécialiste — question précise, contexte, et le texte intégral des documents utiles pour CETTE partie.
3. **Assembler** :
   - L'essentiel en 3 lignes (la réponse à la demande d'origine).
   - Par domaine : ce que dit le spécialiste (attribué), ses réserves.
   - Points de tension entre les avis, et qui doit trancher.
   - Prochaines étapes (qui fait quoi), sans inventer de date ni de responsable.
4. **Vérifier** avant d'envoyer : chaque affirmation vient d'un spécialiste ou d'un document ; rien n'est ajouté.
